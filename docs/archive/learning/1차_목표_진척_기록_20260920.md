## 3.1 1차 목표 — isaac 에서 쌓기 (2026-09-19 확정)

**과제 하나다.** 탁자 위에 실린더와 블럭이 있고, **블럭을 실린더 위에 쌓는다.**
`/scene/reset` 으로 매 회 무작위 배치하고 그 과정을 녹화해 학습 데이터를 만든다.

> **isaac 을 먼저 하는 것은 대안이자 순서다.** 실기가 **Panda + Robotiq 2F-85** 라
> 원래 순서는 펑션베이(같은 구성)지만, 그 시뮬레이터가 개발 중이고 **peg-in-hole 환경이
> 서기까지 벤더 작업이 필요해 기다려야 한다.** isaac 은 지금 학습·추론을 바로 돌릴 수
> 있어 **그동안 경험을 쌓는다.** 펑션베이 환경이 서면 같은 흐름으로 peg-in-hole 을 하고,
> 만족스러우면 **실기 Panda + Robotiq** 으로 간다.

### 이미 있는 것

| | 상태 |
|---|---|
| 씬 물체 | `isaac_scene.json` 에 **`cylinder_a` · `block_a`**(둘 다 `dynamic: true`) · `table` |
| 무작위 배치 | isaac 이 **`/scene/reset` 을 제공한다**(mock 과 같은 계약. 펑션베이만 없다) |
| **작업 절차** | **`robot-twin-stack` CLI 가 이미 한다** — `reset_and_stack()` 이 배치 → 쌓기를 하고 **성공 여부를 `bool` 로 돌려준다.** `--repeat N` 도 있다. **기본값이 `--source block_a --base cylinder_a` 라 그대로 쓰면 된다** |

| export | E1 ~ E7 구현 완료. `ros2 run rdfp export` |
